# Asset licences and sources (Local Cut library)

All assets are loaded on demand from public CDNs (jsDelivr). Nothing is copied into this repo except small index files. No credit lines are required or shown in the app.

| Asset | Source | Licence | Pinned version |
|---|---|---|---|
| Icons (outline + filled, 4,658 after exclusions; brand logos excluded) | Tabler Icons, https://github.com/tabler/tabler-icons | MIT (https://tabler.io/license) | npm @tabler/icons 3.53.0 |
| Icons (2,123) | Lucide, https://github.com/lucide-icons/lucide | ISC (https://lucide.dev/license) | npm lucide-static 1.81.0 |
| Emoji metadata (1,653 emoji, English labels and tags) | Emojibase, https://github.com/milesj/emojibase (Unicode CLDR data) | MIT (data derived from Unicode CLDR, Unicode licence) | npm emojibase-data 18.0.0 |
| Emoji rendering | the device's own emoji font (no emoji images are shipped) | n/a | n/a |
| Transitions (398 GLSL shaders, only files marked "License: MIT") | https://github.com/gl-transitions/gl-transitions | MIT | commit eb1b3fe |
| Sound effects (408) | https://github.com/Reodelbasalan/adbertiser-sfx | CC0 1.0 (their LICENSE file; author states sounds are synthesized by code) | commit ed6482e |
| Sound effects: Impact Sounds (130), Digital Audio (62), Sci-Fi Sounds (73), Music Jingles (85) | Kenney (https://kenney.nl) via https://github.com/Boyquotes/kenney-*-for-godot | CC0 1.0 | pinned commits in sounds_kenney.json |

| Backgrounds | generated in code (gradients, dots, grid, waves, grain, stripes, blobs) | own work | n/a |

Not included on purpose: anything Creative Commons Attribution, ShareAlike or NonCommercial (for example Twemoji, OpenMoji, LottieFiles, Pixabay, Freesound), and any brand logos.

Gaps (honest): no full-length CC0 background music library was found on GitHub; only short Kenney jingles. Animated icons/Lottie with a CC0/MIT licence were not found; icons are animated in code instead.
